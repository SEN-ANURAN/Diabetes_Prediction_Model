# 🩺 Diabetes Prediction Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning techniques to predict whether a person is likely to have diabetes based on medical diagnostic parameters. The model is trained on the Pima Indians Diabetes Dataset and uses Support Vector Machine (SVM) for classification.

The project includes data preprocessing, exploratory data analysis (EDA), visualization, model training, evaluation, and prediction.

---

## 🎯 Objectives

- Analyze diabetes-related health data.
- Identify important features influencing diabetes prediction.
- Build an accurate classification model using SVM.
- Visualize patterns and relationships within the dataset.
- Predict diabetes risk based on patient health parameters.

---

## 📊 Dataset Information

The dataset contains the following attributes:

| Feature | Description |
|----------|------------|
| Pregnancies | Number of pregnancies |
| Glucose | Plasma glucose concentration |
| BloodPressure | Diastolic blood pressure |
| SkinThickness | Triceps skin fold thickness |
| Insulin | Serum insulin level |
| BMI | Body Mass Index |
| DiabetesPedigreeFunction | Diabetes inheritance factor |
| Age | Age of patient |
| Outcome | Target Variable (0 = Non-Diabetic, 1 = Diabetic) |
